\label{app:repro}

\section{Môi trường}
Luồng mô phỏng chạy trên Linux với các công cụ: Verilator $\ge5$ (đã dùng 5.032); trình biên dịch chéo \code{riscv64-unknown-elf-gcc} (đã dùng bản 14); Python 3 với NumPy; GNU make và g++. Mã nguồn PicoRV32 nằm trong thư mục \code{third\_party/picorv32} (giấy phép ISC). Trên Debian/Ubuntu:
\begin{lstlisting}[style=codebash]
sudo apt-get install verilator gcc-riscv64-unknown-elf make g++ python3 python3-numpy
\end{lstlisting}
Hoặc dùng ảnh Docker của dự án (Phụ lục~\ref{app:docker}).

\section{Mô phỏng}
\begin{lstlisting}[style=codebash]
make test N=8                  # unit test sa_top: 26 tests
make wave N=4                  # same, with sa_top.vcd waveform
make soc  N=8 FW=gemm_demo     # GEMM CPU vs NPU, M = 1, 8, 32, 64
make soc  N=8 FW=selftest      # 24 post-processing trials
make soc  N=8 FW=cnn           # LeNet-5, 8 images (about 2 minutes)
make soc  N=8 FW=lstm          # LSTM, 16 images, batch 1 and 16
bash scripts/preflight.sh      # everything above for N=4 and N=8, summary table
\end{lstlisting}
Log của mỗi lần chạy nằm ở \code{build\_soc\_N<N>/<FW>.log}; các bản đã lưu ở \code{results/}.

\section{FPGA DE10-Nano}
Kiểm tra firmware bằng công cụ mở trên bản đồ bộ nhớ DE10, với PicoRV32 thay cho Nios~V (Linux, Verilator):
\begin{lstlisting}[style=codebash]
de10/sim/run_sim.sh cnn 8          # build de10/fw + run on tb_de10_map
de10/sim/run_elf.sh de10/out/cnn_niosvg.elf tb_de10_map   # final ELF, mtvec write -> NOP
de10/sim/run_elf.sh de10/out/cnn_picorv32.elf tb_pico_avmm # real Avalon bridge, random waitrequest
\end{lstlisting}
Biên dịch Quartus (Quartus Prime Lite 25.1std; trên máy xây dựng là LXC 190, thư mục \code{/root/ee5223/de10}):
\begin{lstlisting}[style=codebash]
source env.sh
FW=selftest scripts/build.sh                 # Nios V/g (default); FW = selftest|cnn|lstm
NIOSV_CORE=intel_niosv_m scripts/build.sh    # Nios V/m (rv32i firmware automatically)
NPU_RTL_VARIANT=ref scripts/build.sh         # proj/rtl (via rtl_compat) instead of rtl_fpga
scripts/build_pico.sh                        # licence-free PicoRV32 system
\end{lstlisting}
Chạy trên board (Windows, cmd có \code{quartus\textbackslash bin64} trong PATH; theo \code{de10/BOARD\_RUNBOOK.md}):
\begin{lstlisting}[style=codebash]
jtagconfig          :: expect "DE-SoC [USB-1]": SOCVHPS (@1) + 5CSEBA6 (@2)
quartus_pgm -c "DE-SoC [USB-1]" -m JTAG -o "p;C:\npu\de10_nano_npu_picorv32_selftest.sof@2"
juart-terminal -c "DE-SoC [USB-1]" -d 2 -i 0     :: then press KEY0 to re-run
:: older installs: nios2-terminal -c "DE-SoC [USB-1]" -d 2 -i 0
niosv-download -g -c "DE-SoC [USB-1]" -d 2 C:\npu\cnn_niosvg.elf   :: Nios V/g or /m only
certutil -hashfile C:\npu\de10_nano_npu_picorv32_selftest.sof SHA256  :: compare with SHA256SUMS.txt
\end{lstlisting}
Để đổi chương trình trong một \code{.sof} đã có mà không fit lại: chép tệp \code{.hex} thành \code{onchip\_init.hex} (với PicoRV32 là \code{onchip\_init\_pico.hex}), rồi chạy \code{quartus\_cdb <prj> -c <prj> --update\_mif} và \code{quartus\_asm <prj> -c <prj>}.
